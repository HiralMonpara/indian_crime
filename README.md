# Crime Data Analysis in India Using Python

## 📌 Project Overview
This project focuses on analyzing crime data in India using Python. The objective is to identify crime patterns, understand crime distribution across cities, analyze victim demographics, and examine case closure rates.

The project uses data analysis and visualization techniques to explore crime-related trends and generate meaningful insights from the dataset.

## 🎯 Project Objectives
- Identify cities with the highest and lowest crime counts.
- Analyze year-wise crime trends.
- Find the most common crime types.
- Study crime distribution by victim age and gender.
- Analyze crime domains and weapon usage.
- Compare case closure rates across cities and crime domains.
- Explore the relationship between police deployment and case closure.

## 🛠️ Tools and Technologies
- Python
- Pandas — Data manipulation and analysis
- NumPy — Numerical operations
- Matplotlib — Data visualization
- Jupyter Notebook — Data analysis and experimentation

## 📂 Project Files
- `Python_Project_crime.ipynb` — Jupyter Notebook containing data cleaning, exploratory data analysis, calculations, and visualizations.
- `crime_dataset_india.csv` — Dataset used for the analysis.

## 📊 Dataset Description
The dataset contains **40,160 records and 15 columns**, covering information such as:

- Report Number
- Date Reported
- Date of Occurrence
- Time of Occurrence
- City
- Crime Code
- Crime Description
- Victim Age
- Victim Gender
- Weapon Used
- Crime Domain
- Police Deployed
- Case Closed
- Date Case Closed

The dataset includes crime categories such as Violent Crime, Other Crime, Fire Accident, and Traffic Fatality.

## 🔍 Analysis Performed
1. **Data Exploration:** Examined dataset structure, data types, descriptive statistics, missing values, and duplicate records.
2. **City-wise Analysis:** Compared crime counts across cities.
3. **Time-based Analysis:** Examined year-wise crime trends and changes in crime types.
4. **Crime Type Analysis:** Identified common crime descriptions and frequently used weapons.
5. **Victim Demographics:** Analyzed crime distribution by age group and gender.
6. **Case Closure Analysis:** Compared closure rates across cities and crime domains.
7. **Police Deployment Analysis:** Compared average police deployment for closed and open cases.
8. **Data Visualization:** Created bar charts, line charts, and pie charts to present findings.

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

4. Keep the CSV dataset and notebook in the same project folder.
5. Open `Python_Project_crime.ipynb` in Jupyter Notebook.
6. Update the dataset path in the notebook if required.
7. Run the notebook cells to reproduce the analysis.
